Özgeçmiş & Mesleki İlgi

Ben Kevser ÇETKİN. Akdeniz Üniversitesi Teknik Bilimler MYO Bilgisayar Programcılığı bölümü öğrencisiyim. Web teknolojilerine olan ilgim lise yıllarında basit işaretleme dilleriyle başladı. Günümüzde modern arayüz mimarileri, semantik kodlama, SEO kuralları ve kullanıcı deneyimi (UX) konularında kendimi geliştirmekteyim.

Bu projede CSS kutu modelleme, RWD düzenleri ve HTML5 semantik yapısı üzerine çalışıyorum. Yeni öğrendiklerimi küçük örneklerle uygulayıp geliştirmeye devam ediyorum.

Kodlama Standartlarım & Özel Notasyonlar

Ders kapsamında öğrendiğimiz semantik standartlar doğrultusunda web sayfalarında W3C onaylı temiz kod blokları kullanıyorum. Örneğin CSS'te sınıf seçicileri için .card-header veya değişken tanımlamalarında var(--primary-color) yapısını tercih ediyorum: 

/* Kutu Modelleme & CSS Specificity Örneği */
#wrapper {
  max-width: 1140px;
  margin: 0 auto;
  box-sizing: border-box; /* Padding ve border genişliği etkilemez */
}

@media screen and (max-width: 768px) {
  .two-column-layout {
    display: flex;
    flex-direction: column; /* Tablet ve mobil cihaz uyumu */
  }
}
