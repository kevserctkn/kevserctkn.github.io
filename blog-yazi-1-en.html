Why HTML5 matters

A web page is more than colors and boxes. Meaningful elements make its structure clearer for people and assistive technologies. Semantic HTML describes a section’s purpose: header for the introduction, nav for navigation, and main for the primary content.

02
02 / Chapter

The page skeleton

A portfolio might contain an introduction, navigation, main content and footer. Article is useful for self-contained content such as a blog post; section groups related material under a topic.

03
03 / Chapter

Mini project: Portfolio skeleton

This small HTML example separates navigation, main content and footer. Save it as an HTML file and open it in a browser. It is a teaching example, not a claim about completed coursework.

CODE / EXAMPLE

Code Example

Try this small example in your own practice file.

<header>Merhaba!</header>
<nav><a href="#hakkimda">Hakkımda</a></nav>
<main><section id="hakkimda">
<h1>Portfolyom</h1>
<p>Web tasarımını öğreniyorum.</p>
</section></main>
<footer>2026</footer>

Heading hierarchy

Headings organize ideas rather than simply making text large. H1 identifies the main topic, while H2 and H3 can structure sections. This assignment asks for one H1 per page; that is an assignment rule rather than a universal HTML restriction.

Accessibility details

Meaningful alt text, keyboard-friendly links and associated form labels improve accessibility. Decorative images may use empty alt text. Descriptive link text is better than vague “click here” labels.

08
06 / Chapter

Review checklist

Before delivery, review headings, links, image alt text and the mobile layout. HTML validators can help spot structural mistakes. Choose elements for their meaning, not just to satisfy a checklist.
