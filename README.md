# Kevser Çetkin — Kişisel Portfolyo

Türkçe ve İngilizce hazırlanmış statik HTML, CSS ve JavaScript sitesidir. Türkçe giriş `index.html`, İngilizce giriş `index-en.html` dosyasıdır.

## Yerel açılış

Arşivi açıp `index.html` dosyasını tarayıcıda açabilirsiniz. Python kuruluysa `baslat.bat` yerel sunucu başlatır.

## Canlı yayın ve form

Doğrulanmış canlı adres: https://kevserctkn.github.io/ (GitHub Pages). Özel alan adı satın alındıysa bu projeyle DNS bağlantısı ayrıca doğrulanmalıdır. İletişim formu e-posta uygulamasında taslak açar; otomatik e-posta göndermez.

## Proje notları

Hakkımda, proje, blog, galeri ve iletişim sayfalarının Türkçe ve İngilizce sürümleri bulunur. Grafik örnekleri bu portfolyo için hazırlanmış temsili çalışmalardır; Grafik Animasyon I dersinde yapılmış çalışmalar olarak tanıtılmaz. Öğretmen özellikle internet kaynaklı örnek bekliyorsa kaynakların ayrıca belirtilmesi gerekir.

`SKILLS.md` tasarım ilkelerinin nasıl uygulandığını, `kaynak.txt` ise kullanılan görsel ve tasarım kaynaklarını açıklar.

## Vize teslimi

Proje arşivi `20261132805-WEB.zip` dosyasıdır. Teams yönergesinin istediği özel yöntem için aynı arşivin `.PDF` uzantılı kopyası yüklenir; bu dosya gerçek bir PDF belgesi değildir. Word ekran görüntüsü raporu ve YouTube tanıtım bağlantısı Teams'e ayrı alanlardan eklenir. Yönetim paneli zorunlu değildir.
